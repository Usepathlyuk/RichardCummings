# Workspace

## Overview

This workspace contains one runnable application: Richard Cummings' public portfolio.

## Stack

- **App**: React + Vite
- **Monorepo tool**: pnpm workspaces
- **Node.js version**: 24
- **Package manager**: pnpm
- **TypeScript version**: 5.9
- **Animation**: Framer Motion
- **Styling**: Tailwind CSS

## Key Commands

- `pnpm run dev` — run the portfolio locally
- `pnpm run typecheck` — typecheck the portfolio
- `pnpm run build` — build the portfolio for production

## Portfolio

- **Location**: `artifacts/portfolio`
- **Preview path**: `/`
- **Purpose**: Personal professional portfolio website for Richard Cummings, IT Asset & Configuration Leader and SaaS Founder
- **Sections**: Hero, About, Career Timeline, UsePathly showcase, Key Stats, Skills, Certifications & Education, and Contact
- **Assets**: `artifacts/portfolio/public/profile.jpg` and `artifacts/portfolio/public/Richard_Cummings_CV.pdf`
- **Content**: `artifacts/portfolio/src/data/content.ts`
